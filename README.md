# Cognexa website

Static site with a content manager and a small serverless backend, all hosted on Netlify.

| Part | What it is | Where |
|---|---|---|
| Pages | 33 static pages generated by `node src/build.mjs` | `src/` → `public/` |
| Content | Every editable piece of copy, as JSON | `content/` |
| CMS | Decap CMS 3.17.1 (self-hosted), edits `content/` through GitHub | `/admin` |
| Backend | Netlify Functions + Netlify Blobs (no database to run) | `netlify/` |
| Leads dashboard | Every enquiry, with status, owner, notes and CSV export | `/admin/leads/` |

## How it fits together

```
Editor ──/admin──▶ Decap CMS ──commit──▶ GitHub ──▶ Netlify build (node src/build.mjs) ──▶ live site
Visitor ──form──▶ Netlify Forms ──submission-created──▶ leads store ──▶ email / Slack ──▶ /admin/leads/
Visitor ──/check/──▶ POST /api/check ──▶ checks store ──▶ stats in /admin/leads/
```

## Content (CMS collections)

* **Industries**: the five industry pages, plus their homepage tiles, Industries page cards and menu entries.
* **Services**: the eight discipline pages and the Services menu.
* **Thinking**: articles, with drafts, dates, topics, related articles and an image per article.
* **Case studies**: tick *Published* to give a case its own page. Unpublished cases are listed as "being written up".
* **Settings**: site and contact details (phones, main call to action), SEO titles and descriptions per page, client logos (with an optional "what we did" line), and the privacy policy.

Changes go through **drafts → review → publish** (editorial workflow). Publishing commits to GitHub and Netlify rebuilds in about a minute.

## Backend endpoints

| Route | Who | What |
|---|---|---|
| `submission-created` (event) | Netlify | Every verified form submission is saved as a lead and the team is notified |
| `GET /api/leads` | admin | List leads (`?status=`, `?q=`, `?format=csv`) |
| `GET/PATCH/DELETE /api/leads/:id` | admin | Read, update status, owner and notes, or erase a lead |
| `POST /api/check` | public | Store an anonymous hesitation-check result |
| `GET /api/check/stats` | admin | Totals by lever, industry, pace and day |

Admin routes need `Authorization: Bearer <ADMIN_TOKEN>`. The dashboard asks for the token and keeps it in the browser tab only.

## Environment variables (Netlify → Site configuration → Environment variables)

| Variable | Required | Purpose |
|---|---|---|
| `ADMIN_TOKEN` | yes | Password for the leads dashboard and admin API. Use 32+ random characters. |
| `RESEND_API_KEY` | for email | API key from resend.com |
| `NOTIFY_TO` | for email | Who gets new-lead emails, comma separated |
| `NOTIFY_FROM` | for email | Sender, e.g. `Cognexa website <hello@cognexadigital.com>` (domain verified in Resend) |
| `AUTOREPLY` | optional | `on` sends the visitor a "we have your brief" email |
| `SLACK_WEBHOOK_URL` | optional | Posts each new lead to a Slack channel |

## One-time setup

1. **Put the project on GitHub.** Create a repository (private is fine) and push this folder to it.
2. **Point the CMS at it.** Run `node tools/setup-cms.mjs <owner>/<repo>`, then commit and push.
3. **Connect Netlify to the repository.** In the `cognexa-digital` project: *Project configuration → Build & deploy → Link repository*. Build settings come from `netlify.toml`. Drag-and-drop deploys can't run functions, so this step is needed for the backend.
4. **Turn on GitHub sign-in for the CMS.** Create a GitHub OAuth app (*GitHub → Settings → Developer settings → OAuth Apps*). Set the callback URL to `https://api.netlify.com/auth/done`. Then add its client ID and secret in Netlify under *Project configuration → Access & security → OAuth → Install provider → GitHub*. Each editor needs write access to the repository.
5. **Add the environment variables** above, then trigger a deploy.
6. **Turn on form notifications** in Netlify Forms if you also want Netlify's own emails. The function already emails through Resend.

## Local development

```bash
npm install
npm test                                   # 12 tests: backend, content and build
ADMIN_TOKEN=dev-token-1234567890 npm run dev   # site + functions + forms on http://localhost:8888
npx decap-server                           # in a second terminal: edit content at http://localhost:8888/admin
```

Locally, leads and check results are saved as JSON in `.data/` (git-ignored). On Netlify they go to Netlify Blobs.
